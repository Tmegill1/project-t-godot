# Slice 0 Implementation Plan — wave economy, visible limits, maps 2 and 3

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the player a decision between waves, make the tower limits the game already enforces visible, tune the gold curve so the new income does not break it, and add The Fork and The Coils.

**Architecture:** Every new rule is a pure static function in `sim/` or a constant in `data/`, consumed by both `game/game_board.gd` and `sim/harness.gd` so there is never a second rules implementation. The two new maps are algorithmic builders ported from upstream TypeScript, each seeded and pinned by a golden-board test. Larger maps are fitted by changing the window's base resolution per map, never by a camera or a node transform — world space must stay identical to map pixel space.

**Tech Stack:** Godot 4.7.1, GDScript only. No C#, no addons, no external dependencies.

**Spec:** [`docs/superpowers/specs/2026-08-24-slice-0-design.md`](../specs/2026-08-24-slice-0-design.md)

## Global Constraints

- **GDScript only.** No C#, no addons, no external dependencies.
- **`sim/` and `data/` must never touch the engine** — no `Node`, `get_tree()`, `preload`, `@onready`, `@export`, scene types, `load(`, `ResourceLoader`, `$`/`%` node shorthand, engine RNG, or `Time.` / `Engine.` / `OS.`. `test/test_sim_purity.gd` enforces this.
- **Sim time is milliseconds.** Callers convert with `delta * 1000.0`.
- **Combat uses distance arithmetic, never physics.**
- **All randomness goes through `sim/rng.gd`.**
- **One rule, one home.** If the harness and the board both need an answer, it lives in `sim/` and both call it.
- **Every `test_*` method is declared `-> bool` and ends `return true`**, including at every early return. This is the crash sentinel.
- **No `await` in a test method.**
- **`add_child()` does not resolve `@onready` in tests.** Call `node.notification(Node.NOTIFICATION_READY)` explicitly after `add_child()`.
- **Any test reading tile coordinates calls `Grid.set_active()` first.**
- **A green run prints ~118 `SCRIPT ERROR` lines to stderr and that is expected.** Judge by the summary line and exit code. *New* noise is a defect.
- **Run the suite with:** `godot --headless --quit --script test/run_tests.gd` (exit 0 = pass).
- **Only when adding a new `class_name`:** run `godot --headless --import` first, or you get "Identifier not declared".
- **Running the game through the Godot MCP rewrites `project.godot`.** `git diff project.godot` and strip the injected `McpInteractionServer` autoload before every commit. The `AudioManager` autoload entry is legitimate — do not delete it.

**Tuned values, exact (spec §4.6):** `GOLD_PER_WAVE = 0.025`, `MIN_GOLD_MODIFIER = 0.40`.

**Ported economy constants, exact (spec §4.1):** wave-clear base 20, per-wave 5, fast-clear 20000ms, slow-clear 60000ms, max speed bonus 40. Call-early prep 20000ms, 3 gold/sec, max 45. Interest 5% per wave, max 30, minimum balance 50.

```gdscript
## Gold paid for a kill, after the wave's gold modifier and the killing
## tower's gold effects.
##
## Order is load-bearing and tested. The WAVE modifier applies to the base
## reward first, then the tower's multiplier applies to that scaled figure,
## then the flat bonus is added last and is never itself multiplied - which
## is what the tier descriptions say. So the Bounty Hunter branch multiplies
## what the wave actually pays rather than an unscaled number, and a flat
## bonus keeps its full value however deep the wave is.
##
## Rounds to nearest rather than flooring, matching the reference's kill
## payout; gold is an integer, and a half-gold difference the HUD cannot show
## would drift from the banked total.
##
## `gold_modifier` defaults to 1.0 so a caller with no wave in hand - and
## every pre-existing test - reads the unscaled reward.
static func kill_reward(base_reward: int, source: Dictionary,
		gold_modifier: float = 1.0) -> int:
	var scaled := float(maxi(0, base_reward)) * gold_modifier
	var multiplier := float(source.get(&"gold_multiplier", 1.0))
	var flat := int(source.get(&"bonus_gold_per_kill", 0))
	return maxi(0, roundi(scaled * multiplier) + flat)
```

Append to `sim/economy.gd`:

```gdscript
# --- Wave economy ---------------------------------------------------------

## Gold paid for clearing a wave, itemised.
##
## Itemised rather than totalled because the UI must be able to tell the
## player WHY they were paid, or the incentives stay invisible.
##
## DIVERGENCE from the reference, deliberate: upstream's waveClearReward also
## folds interest into this call, and computes interestOn twice in one
## function body. Interest is its own function here, called once by the
## board - which is where the banked balance already lives. Same result, one
## responsibility each.
static func wave_clear_bonus(wave: int, clear_ms: float) -> Dictionary:
	var base := int(Economy.WAVE_CLEAR["base_bonus"]) \
		+ maxi(0, wave) * int(Economy.WAVE_CLEAR["bonus_per_wave"])

	var fast := float(Economy.WAVE_CLEAR["fast_clear_ms"])
	var slow := float(Economy.WAVE_CLEAR["slow_clear_ms"])
	# maxf(1.0, ...) so a table where the two thresholds are equal divides by
	# one rather than by zero.
	var span := maxf(1.0, slow - fast)
	var slowness := (maxf(0.0, clear_ms) - fast) / span
	var speed := roundi(float(Economy.WAVE_CLEAR["max_speed_bonus"])
		* clampf(1.0 - slowness, 0.0, 1.0))

	return {"base": base, "speed": speed}

## Interest on banked gold, capped, floored, and only above a minimum.
static func interest_on(banked: int) -> int:
	if banked < int(Economy.INTEREST["minimum_balance"]):
		return 0
	return mini(int(Economy.INTEREST["max_per_wave"]),
		int(floor(float(banked) * float(Economy.INTEREST["rate_per_wave"]))))

## Gold for starting a wave early, proportional to the prep time given up.
##
## Whole seconds only, and capped, so rushing cannot dominate the wave-clear
## bonus and reduce the game to a race.
static func call_early_bonus(remaining_ms: float) -> int:
	var window := float(Economy.CALL_EARLY["prep_duration_ms"])
	var seconds := int(floor(clampf(remaining_ms, 0.0, window) / 1000.0))
	return mini(int(Economy.CALL_EARLY["max_bonus"]),
		seconds * int(Economy.CALL_EARLY["gold_per_second"]))
```

```gdscript
class_name Map2

## Builds "The Fork" — the 26x17 second map.
##
## Two entrances, top left and bottom left, converging at row 7 and running
## right to the goal. That convergence is the map's whole point: a tower on
## the joined stretch covers both streams, and one before it covers only half
## the wave.
##
## Note what two spawns MEAN for difficulty: the full wave composition runs
## down EVERY path (see GameBoard._spawn), so this map fields twice the
## enemies of the same wave number on The Pass. That is why its starting gold
## is 250 against The Pass's 100.
##
## Takes an Rng so the blocked-tile layout is reproducible.

const GRID_COLS := 26
const GRID_ROWS := 17

const MAX_ADJACENT_BLOCKED := 5
const MAX_DISTANT_BLOCKED := 7
const MAX_TOTAL_BLOCKED := 12

static func build(rng: Rng = null) -> Array:
	if rng == null:
		rng = Rng.new(Seeds.DEFAULT_MAP2_SEED)

	var map: Array = []
	for r in GRID_ROWS:
		var row: Array = []
		for c in GRID_COLS:
			row.append(Tiles.BUILDABLE)
		map.append(row)

	# Path legs, authored as [col, row] pairs.
	var path_coords: Array[Vector2i] = []
	# Top left entrance: right along row 1, then down column 10 to row 7.
	for c in range(0, 10):
		path_coords.append(Vector2i(c, 1))
	for r in range(1, 7):
		path_coords.append(Vector2i(10, r))
	# Bottom left entrance: right along row 12, then up column 9 to row 7.
	for c in range(0, 9):
		path_coords.append(Vector2i(c, 12))
	for r in range(12, 7, -1):
		path_coords.append(Vector2i(9, r))
	# The joined stretch: row 7, right to the goal.
	for c in range(9, GRID_COLS - 1):
		path_coords.append(Vector2i(c, 7))

	var path_set := {}
	for coord in path_coords:
		map[coord.y][coord.x] = Tiles.PATH
		path_set[Vector2i(coord.x, coord.y)] = true

	map[1][0] = Tiles.SPAWN
	map[12][0] = Tiles.SPAWN
	map[7][GRID_COLS - 2] = Tiles.GOAL

	# The endpoint sprites are drawn 3x3, so the ground they cover is blocked
	# rather than left buildable underneath the artwork.
	_block_box(map, 0, 2, 0, 2)     # top spawn
	_block_box(map, 11, 13, 0, 2)   # bottom spawn
	var goal_row := 7
	var goal_col := GRID_COLS - 2
	_block_box(map, goal_row - 1, goal_row + 1, goal_col - 1, goal_col + 1)

	# Scatter. Row 0 is reserved for UI; the last column for the tower menu.
	var adjacent: Array = []
	var distant: Array = []
	for r in GRID_ROWS:
		for c in GRID_COLS:
			if map[r][c] != Tiles.BUILDABLE:
				continue
			if r == 0 or c == GRID_COLS - 1:
				continue
			if _is_adjacent_to_path(r, c, path_set):
				adjacent.append(Vector2i(c, r))
			else:
				distant.append(Vector2i(c, r))

	var shuffled_adjacent := rng.shuffle(adjacent)
	var shuffled_distant := rng.shuffle(distant)

	var blocked_count := 0
	var adjacent_blocked: int = mini(MAX_ADJACENT_BLOCKED, shuffled_adjacent.size())
	for i in adjacent_blocked:
		var t: Vector2i = shuffled_adjacent[i]
		map[t.y][t.x] = Tiles.BLOCKED
		blocked_count += 1

	var remaining := MAX_TOTAL_BLOCKED - blocked_count
	var distant_blocked: int = mini(MAX_DISTANT_BLOCKED, mini(shuffled_distant.size(), remaining))
	for i in distant_blocked:
		var t: Vector2i = shuffled_distant[i]
		map[t.y][t.x] = Tiles.BLOCKED

	return map

static func _block_box(map: Array, r0: int, r1: int, c0: int, c1: int) -> void:
	for r in range(r0, r1 + 1):
		for c in range(c0, c1 + 1):
			if r >= 0 and r < GRID_ROWS and c >= 0 and c < GRID_COLS \
					and map[r][c] == Tiles.BUILDABLE:
				map[r][c] = Tiles.BLOCKED

static func _is_adjacent_to_path(row: int, col: int, path_set: Dictionary) -> bool:
	var directions: Array[Vector2i] = [Vector2i(0, -1), Vector2i(0, 1), Vector2i(-1, 0), Vector2i(1, 0)]
	for d in directions:
		var nr := row + d.y
		var nc := col + d.x
		if nr < 0 or nr >= GRID_ROWS or nc < 0 or nc >= GRID_COLS:
			continue
		if path_set.has(Vector2i(nc, nr)):
			return true
	return false
```

```gdscript
class_name Map3

## Builds "The Coils" — the 28x16 third map.
##
## One entrance and a serpentine route that folds back on itself three times.
## The folds are the whole point: each straight is long enough that a tower
## placed on a bend covers two passes, which is why its tower budget (18) is
## LOWER than The Fork's (20) despite the wider board. More ground does not
## mean more difficulty when the ground doubles up.
##
## Takes an Rng so the blocked-tile layout is reproducible.

const GRID_COLS := 28
const GRID_ROWS := 16

const SPAWN_ROW := 2
const GOAL_ROW := 13
const GOAL_COL := GRID_COLS - 2

## Scatter bounds. Unlike The Pass and The Fork there is NO combined ceiling:
## upstream takes six from the adjacent list and nine from the distant one
## independently. Preserved deliberately.
const MAX_ADJACENT_BLOCKED := 6
const MAX_DISTANT_BLOCKED := 9

static func build(rng: Rng = null) -> Array:
	if rng == null:
		rng = Rng.new(Seeds.DEFAULT_MAP3_SEED)

	var map: Array = []
	for r in GRID_ROWS:
		var row: Array = []
		for c in GRID_COLS:
			row.append(Tiles.BUILDABLE)
		map.append(row)

	_run_row(path_coords, SPAWN_ROW, 0, 23)
	_run_col(path_coords, 23, SPAWN_ROW, 6)
	_run_row(path_coords, 6, 23, 3)
	_run_col(path_coords, 3, 6, 10)
	_run_row(path_coords, 10, 3, 23)

	map[GOAL_ROW][GOAL_COL] = Tiles.GOAL

	_block_around(map, SPAWN_ROW, 0)
	_block_around(map, GOAL_ROW, GOAL_COL)

	var adjacent: Array = []
	var distant: Array = []
	for r in GRID_ROWS:
		for c in GRID_COLS:
			if map[r][c] != Tiles.BUILDABLE:

static func _run_row(out: Array[Vector2i], row: int, from_col: int, to_col: int) -> void:
	var step := 1 if from_col <= to_col else -1
	var c := from_col
	while (c <= to_col) if step > 0 else (c >= to_col):
		out.append(Vector2i(c, row))
		c += step

static func _run_col(out: Array[Vector2i], col: int, from_row: int, to_row: int) -> void:
	var step := 1 if from_row <= to_row else -1
	var r := from_row
	while (r <= to_row) if step > 0 else (r >= to_row):
		out.append(Vector2i(col, r))
		r += step

static func _block_around(map: Array, row: int, col: int) -> void:
	for r in range(row - 1, row + 2):

					and map[r][c] == Tiles.BUILDABLE:

	return false
```
